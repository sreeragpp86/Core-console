## Featured Systems Index

* **[Pulse](https://github.com/sreeragpp86)** — *Real-Time Educational Telemetry Engine* (`FastAPI`, `WebSockets`, `PostgreSQL`, `Redis`, `Next.js`)  
  Dual-path WebSocket ingestion gateway handling 500+ concurrent event streams with an asynchronous write-behind memory buffer that cuts PostgreSQL transaction overhead by >98%.

* **[Conduit](https://github.com/sreeragpp86)** — *DAG AI Workflow Orchestrator* (`Next.js`, `React Flow`, `FastAPI`, `SSE`, `Zustand`)  
  Spatial node-based workflow engine utilizing Kahn's Topological Sort ($O(V + E)$) for cycle detection and Server-Sent Events (SSE) for live per-node execution telemetry.

* **[FluxMedia](https://github.com/sreeragpp86)** — *Distributed Media Processing Task Queue* (`FastAPI`, `Celery`, `Redis`, `FFmpeg`, `Supabase`)  
  Asynchronous media transcoding pipeline decoupling CPU-bound H.264/HEVC compression (`VideoToolbox`) from main API threads via isolated Celery workers.

* **[Vectra Labs (Infocyle)](https://github.com/sreeragpp86)** — *Full-Stack Learning Management Platform* (`Next.js`, `FastAPI`, `Supabase`)  
  Core web LMS and cohort analytics infrastructure engineered as Co-Founder & CTO[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).

## Local Development

### Prerequisites
* **Node.js** `>= 18.x`
* **npm** or **pnpm**

### Quickstart
```bash
git clone [https://github.com/sreeragpp86/sreerag.dev.git](https://github.com/sreeragpp86/sreerag.dev.git)
cd sreerag.dev
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.
